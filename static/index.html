Бренд: —

          

            Настройки ниже относятся к выбранному в списке слева бренду.
            Создать/копировать/переименовать/удалить — кнопки под списком брендов.
          

          

            
          

        


        

          
Расписание этого бренда

          

            В заданное время (Samara) собирается отчёт за предыдущий день
            и пишется в output/ + Google Sheets. У каждого бренда —
            своё время, независимо от остальных. Повторный запуск в ту же дату перезаписывает данные.
          

          

            
            
          

          

            
            
            
          

          

        


        

          
Ads Manager

          

            Логин/пароль твоего аккаунта в Ads Manager. sheetsStat авторизуется через
            /api/auth/login, получает JWT и дёргает расход по кабинетам —
            никакие VK-токены здесь не хранятся.
          

          

            
            
            
          

        


        

          
Yandex Direct (ads_manager_Yandex)

          

            Логин/пароль пользователя в ads_manager_Yandex. sheetsStat авторизуется через
            /api/auth/login и собирает расход с НДС по всем активным
            кабинетам этого пользователя.
          

          

            
            
            
          

        


        

          
Yandex Metrika

          

            OAuth-токен Яндекса (единый для всех сервисов), ID счётчика и имя цели.
            sheetsStat дёргает Metrika Reports API напрямую и возвращает
            «Достижения цели», «Целевые визиты» и «Конверсию» за день.
          

          

            
            
            
            
            
          

        


        

          
LeadsTech

          

            Можно указать несколько аккаунтов — в каждый уходит одинаковый запрос за день,
            а статистика складывается. Пустой sub1 в строке = общий sub1 бренда,
            пустой Base URL = общий ниже. Пустой пароль при сохранении = «оставить прежний».
          

          

            
              

                НазваниеLoginPassword
                sub1Base URLВкл.
              

            
            
          

          
          

            
            
          

        


        

          
8connect

          

            Логин/пароль 8connect. sheetsStat авторизуется через
            /api/auth/login, дёргает /api/report/list за день
            по указанным ID схем и суммирует расход (пишется в колонку AA —
            слагаемое формулы «Затраты» D) и доход (пишется в AC).
          

          

            
            
            
            
          

        


        

          
Google Sheets

          

            Запись отчёта в таблицу: метрики находят свои колонки по подписям
            строки 2 (редактируются во вкладке «Колонки»), расходы кабинетов —
            по названию кабинета в шапке от AP2. Вкладка выбирается
            по месяцу («Апрель 26»). У нового бренда таблица должна быть копией
            шаблона.
          

          

            
            
            

              
              
            

          

        


        

          
          
        

      


      
      

        

          
Метрики: —

          

            У каждой метрики два независимых имени. Подпись колонки — по ней колонка
            ищется на листе при записи: переименовал в таблице → поменяй здесь.
            Название в системе — как метрика зовётся в отчётах и формулах этой проги;
            на таблицу не влияет. Пустое поле — стандартное значение, изменённые подсвечены
            цветом. Формулы правятся в коде (metrics.py).
          

          

            
            
            
              Расходы кабинетов на листе: имена — строка 2, коэффициенты — строка 1.
              Пусто = AP..EZ. Левее AL сдвинуть нельзя — там метрики из таблицы выше.
