Расписание этого бренда

          

            В заданное время (Samara) собирается отчёт за предыдущий день
            и пишется в output/ + Google Sheets. У каждого бренда —
            своё время, независимо от остальных. Повторный запуск в ту же дату перезаписывает данные.
          

          

            
            
          

          

            
            
            
          

          

        


        

          
Ads Manager

          

            Логин/пароль твоего аккаунта в Ads Manager. sheetsStat авторизуется через
            /api/auth/login, получает JWT и дёргает расход по кабинетам —
            никакие VK-токены здесь не хранятся.
          

          

            
            
            
          

        


        

          
Yandex Direct (ads_manager_Yandex)

          

            Логин/пароль пользователя в ads_manager_Yandex. sheetsStat авторизуется через
            /api/auth/login и собирает расход с НДС по всем активным
            кабинетам этого пользователя.
          

          

            
            
            
          

        


        

          
Yandex Metrika

          

            OAuth-токен Яндекса (единый для всех сервисов), ID счётчика и имя цели.
            sheetsStat дёргает Metrika Reports API напрямую и возвращает
            «Достижения цели», «Целевые визиты» и «Конверсию» за день.
          

          

            
            
            
            
          

        


        

          
LeadsTech

          

            
            
            
            
          

        


        

          
8connect

          

            Логин/пароль 8connect. sheetsStat авторизуется через
            /api/auth/login, дёргает /api/report/list за день
            по указанным ID схем и суммирует расход (пишется в колонку AC —
            слагаемое формулы «Затраты» D) и доход (пишется в AE).
          

          

            
            
            
            
          

        


        

          
Google Sheets

          

            Запись отчёта в таблицу: фикс. ячейки C/E/F/G/AI по строке даты,
            расходы кабинетов — в колонки по названию из AR2:CL2,
            остаток — в A37↓/B37↓. Вкладка выбирается по месяцу
            («Апрель 26»). Раскладка одинаковая у всех брендов — у нового бренда
            таблица должна быть копией шаблона.
